## 4. Approved Visual Direction
The approved AI-RISA visual language for Button 2 Premium PDF reports is:

- midnight-black background
- combat-gold headings, dividers, and frames
- steel-grey grids and secondary panels
- restrained blue for Fighter A identity
- restrained red for Fighter B identity only where needed
- red otherwise reserved for risk, exposure, collapse, failure, or disadvantage
- consistent severity scale
- consistent confidence and evidence panels
- consistent source/disclaimer footer
- premium intelligence-dashboard appearance
- report-grade readability over decorative density

The design standard applies one typography hierarchy, one border and panel system, one spacing grid, one severity scale, one confidence/evidence panel format, one disclaimer footer, and one visual-quality standard across the Button 2 report family.

## 5. Core Rule
All Button 2 premium visuals must look like one proprietary intelligence platform.

However, not every visual uses anatomical heat-map treatment.

The anatomical glow effect is a specialist visual component, not the universal chart style.

## 6. Visual Family Standard
The Button 2 premium PDF must use a shared visual language while matching each visual family to its analytical purpose.

### 6.1 Anatomical Intelligence Heat Maps
Use for:

- target exposure
- fatigue and structural decay
- biomechanical stress
- damage-exposure communication
- training priority

These visuals must include:

- title
- analytical purpose
- fighter identity
- front / rear / side view where relevant
- segmented body regions
- numerical regional scores
- severity legend
- confidence score
- evidence basis
- source/video reference placeholder
- non-medical disclaimer

### 6.2 Fighter Architecture Radar
Use for:

- perception
- decision quality
- structure
- distance control
- rhythm control
- defensive intelligence
- adaptation
- composure

This family must not include anatomical bodies.

### 6.3 Tactical Edge Bar Charts
Use for:

- jab effectiveness
- power output
- ring generalship
- defensive resilience
- counter accuracy
- body attacking
- adaptation speed
- mental composure

Red must be used only for risk or disadvantage, not automatically for Fighter B.

### 6.4 Round-Control Projection Line Graphs
Use for:

- round-by-round control
- pressure shifts
- defensive recovery windows
- structural decline markers
- collapse-risk zones

These visuals must include callout markers for major control shifts.

### 6.5 Scenario and Method Pathway Trees
Use for:

- decision victory pathway
- late stoppage pathway
- contested scorecard pathway
- tactical neutrality pathway

Use gold for the primary pathway, grey for secondary pathways, and red for collapse or high-risk branches.

### 6.6 Ring-Geography / Pressure Maps
Use for:

- centre control
- rope/cage vulnerability
- exit routes
- corner trapping
- pressure-routing
- lateral escape analysis

### 6.7 Decision-Structure Maps
Use for the sequence:

PERCEIVE → CLASSIFY → SELECT → EXECUTE → RECOVER → REASSESS

Failure points include:

- perception delay
- false-cue response
- choice overload
- motor-initiation delay
- failed reset
- repeated tactical error

### 6.8 Pace, Energy, and Fatigue Curves
Use for connected analysis from:

Observed pattern → modelled fatigue progression → affected structure → tactical consequence → coaching response

### 6.9 Training Priority Heat Maps
Use for:

- highest-priority correction
- secondary correction
- stable areas
- monitored areas
- camp focus blocks
- sparring constraints
- coach action dashboards

### 6.10 Scorecard and Probability Tables
Use for:

- decision
- early stoppage
- late stoppage
- draw/variance
- round scoring
- probability integrity

These tables must remain readable and avoid visual overload.

### 6.11 Button 3 Result Comparison Visuals
Use for:

- predicted winner vs actual winner
- predicted method vs actual method
- control-shift model confirmation
- fatigue model confirmation
- collapse-window accuracy
- key analysis miss
- accuracy score
- learning update status

These visuals must connect visually to Button 2 while separating prediction from verified result.

## 7. Page Density Rule
The report must use three visual levels.

### Level 1 -- Hero Visual
One major premium visual per important page or section.

Examples:

- anatomical heat map
- ring-geography map
- architecture radar
- scenario tree

### Level 2 -- Analytical Visual
Supporting visuals such as:

- bar chart
- line chart
- probability plot
- score table

### Level 3 -- Evidence Layer
Small factual panels such as:

- confidence
- sample size
- source quality
- observed vs modelled
- limitations
- analysis ID
- version ID
- disclaimer

## 8. Visual Overload Prohibitions
Prohibit:

- two anatomical skeletons on every page
- excessive glowing effects
- full rainbow heat scales on non-heat-map charts
- dense labels around every object
- decorative interface elements without analytical purpose
- tiny text unreadable on mobile
- cluttered dashboards replacing clear report pages
- red used as a fighter identity colour when it creates severity confusion
- unlabelled heat colours
- medical-looking injury implications without tactical/non-medical disclaimer

## 9. Heat Map Evidence Standard
Each heat map must distinguish:

- observed evidence
- modelled estimate
- confidence level
- source/video basis
- tactical meaning
- medical/non-medical status

Each heat map must include wording equivalent to:

TACTICAL ANALYSIS -- NOT A MEDICAL DIAGNOSIS
