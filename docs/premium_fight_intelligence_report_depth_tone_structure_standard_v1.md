# Premium Fight Intelligence Report — Depth, Tone, and Structure Standard v1

## 1. Purpose
This standard governs the writing depth, tone, section logic, and analytical density of AI-RISA Premium Fight Intelligence Reports. It defines the minimum premium-report narrative standard for future long-form matchup outputs while preserving evidence bounds, source traceability, and internal-only release governance.

## 3. Style Reference Status
The operator-provided Makhachev vs Machado Garry report is accepted as a style, tone, and depth reference only.

- STYLE_REFERENCE_ONLY=YES
- FACT_VERIFIED=NO
- SOURCE_GATED_REQUIRED=YES

It must not be treated as source-verified evidence until Button 1 source verification confirms fight details, event status, fighter records, statistics, venue, date, and fight-week variables.

## 4. Premium Report Tone Standard
Required tone:

- authoritative
- tactical
- evidence-bounded
- analytical
- source-traceable
- calm under uncertainty
- written for serious fight consumers, coaches, analysts, and internal operators

Prohibited tone:

- gambling tout language
- certainty claims
- hype language
- `lock`, `guaranteed`, `sure thing`, `easy money`
- unsupported psychology claims
- unsupported injury claims
- overclaiming based on incomplete public data

## 5. Required Analytical Depth
Premium reports should normally include the following analytical layers, with enough density to explain interaction effects rather than listing isolated facts:

- verified matchup snapshot
- recent performance evidence
- fighter architecture map
- critical tactical question
- standing intelligence
- grappling/fence intelligence
- decision entropy
- mental condition under stress
- energy and physiological warfare
- sequential collapse matrix
- round-by-round projection
- bounded scenario simulation
- winning blueprints for both fighters
- corner command matrix
- live fight intelligence indicators
- risk and unknown-variable register
- final AI-RISA verdict

## 6. Required Premium Report Section Architecture
The default premium report sequence is 20 sections, with a normal operating range of 18 to 22 sections when preface or verification addendum material is needed without reducing analytical depth.

1. Executive Command Dashboard
2. Verified Matchup Snapshot

4. AI-RISA Fighter Architecture Map
5. Critical Tactical Question
6. Standing Intelligence
7. Grappling / Clinch / Fence Intelligence
8. Decision Entropy Analysis
9. Mental Condition and Pressure Stability
10. Energy and Physiological Warfare
11. Sequential Collapse Matrix
12. Round-by-Round Projection
13. AI-RISA Scenario Simulation
14. Fighter A Winning Blueprint
15. Fighter B Winning Blueprint

18. Risk and Unknown-Variable Register
19. Final AI-RISA Verdict
20. Fight-Week Verification Addendum, when applicable

## 7. Evidence Rules
Each factual or analytical claim in a premium report must be classified as one of the following:

- verified source fact
- public statistical input
- model-derived index
- AI-RISA analytical inference
- fight-week pending variable
- unknown / not available

Reports must remain evidence-bounded, source-traceable, public-evidence aware, and explicit about where verification ends and inference begins.

## 8. Numerical Output Rules
- probabilities must be bounded
- confidence must be explained
- uncertainty bands must be included where appropriate
- scenario simulation must be described as model-derived and bounded
- no deterministic prediction language
- no betting advice

## 9. Fighter Architecture Rules
Fighter architecture ratings must be labelled as AI-RISA matchup-specific analytical indices, not official UFC ratings.

## 10. Tactical State Rules
Reports must identify relevant tactical states, including but not limited to:

- long-range open space
- fence-line engagement
- clinch contact
- grounded control
- transitional scramble
- late-round fatigue state

## 11. Decision Entropy Rules
Reports must explain how tactical options expand or contract under pressure, including which reads become simpler, which choices disappear, and which branches become more dangerous as pace, damage, fatigue, or control shifts accumulate.

## 12. Collapse and Failure Rules
Both fighters must receive all of the following:

- winning pathway
- failure pathway
- prohibited errors
- live invalidation conditions

## 13. Corner Command Rules
Premium report language must be translatable into short corner commands so that analysis can be condensed into actionable, time-constrained coaching cues without losing the underlying tactical meaning.

## 14. Fight-Week Verification Rules
Fight-week evidence requires separate verification before it can be promoted from pending variable status:

- weigh-in behaviour
- hydration and recovery
- visible injury
- late opponent/card changes
- stance or tactical changes
- emotional control signals
- referee or venue factors

## 15. Button 1-2-3 Integration
Button 1 must source-verify the matchup and evidence.

Button 2 must generate the premium report using this depth standard.

Button 3 must later compare the final projection against official results.

Controlled learning remains gated and inactive unless separately authorized.

## 16. PDF Design Implication
Premium reports must support longer-form content and should not compress this depth into the smaller evidence-pack PDF.

Separate:

- Evidence Pack PDF = proof-of-system / validation sample
- Premium Fight Intelligence Report = full analytical product

## 17. Customer Boundary
This standard does not authorize customer release.

No report may be sold, delivered, or published until Button 1, Button 2, and Button 3 pass the required internal readiness gates and the operator separately changes release scope.

## 18. Acceptance Criteria
The standard is accepted when:

- it defines the tone
- it defines the depth
- it defines the section sequence
- it preserves internal-only status
- it prevents hype, certainty, gambling-tout language, and unsupported claims
- it connects Button 1, Button 2, and Button 3
