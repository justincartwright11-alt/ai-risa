## 3. FAQ Document

### Frequently Asked Questions (For Stakeholders)

#### **Commercial Readiness**

**Q: Is Button 2 ready for production?**
A: Phase 1–6 is production-ready for paid-pilot evaluation. We're evaluating operator confidence in the proof system. Phase 7 (PDF generation and delivery) requires an additional 1–2 weeks after pilot feedback.

**Q: Can we launch Button 2 to customers today?**
A: Yes, for the proof system and approval gates. No, for PDF generation and delivery (Phase 7+). We recommend starting with paid-pilot to validate operator workflow first.

**Q: What's the difference between Phase 1–6 and Phase 7?**
A: Phase 1–6 = Proof system + operator approval gates (preview only). Phase 7+ = PDF generation + customer delivery (full commercial product).

---

#### **Safety & Compliance**

**Q: Is there any automation bypass?**
A: No. Zero. All operator approval gates are non-bypassable. No auto-approvals, no fast-path shortcuts, no emergency overrides.

**Q: Can operators accidentally write files or database records?**
A: No. Phase 1–6 is preview-only. No file I/O, no database writes, no state mutations. All actions are read-only.

**Q: What if an operator forgets to approve?**
A: Report stays in queue. Operator sees status: "Pending Operator Approval." No auto-expiration or forced approval.

**Q: Can I audit what an operator approved?**
A: Phase 1–6 doesn't log decisions. Phase 7C (archival) will record approval events. Audit trail will be immutable.

---

#### **Operator Experience**

**Q: Will operators understand the proof system?**
A: Pilot will tell us. We've created a runbook with step-by-step guidance. If operators report <4 stars clarity, we simplify proofs before Phase 7.

**Q: What if an operator rejects a report?**
A: Report escalates back to Button 1 for remediation. Operator provides reason (e.g., "Missing sources"). Button 1 team fixes and re-submits.

**Q: How long does an approval decision take?**
A: ~2–5 minutes per report (review content + check proofs + decide). HTML preview generation is <2 seconds.

---

#### **Revenue & Pricing**

**Q: What's the paid-pilot pricing?**
A: Pilot is free/evaluation. No charges. Goal: Gather feedback and validate workflow.

**Q: What's the Phase 7+ pricing model?**
A: Premium per-report fee (after operator approval). Example: $50/report for comprehensive analysis. Pricing approved by business team.

**Q: What's the expected conversion rate?**
A: Conservative: 40% (operator escalations). Optimistic: 60% (high confidence reports). Pilot will provide actual data.

---

#### **Timeline & Effort**

**Q: When does paid-pilot start?**
A: Week of May 19, 2026. 1–2 weeks duration.

**Q: When does Phase 7A (PDF generation) start?**
A: After paid-pilot feedback (late May). Implementation: 2–3 days. Testing: 1 week. Launch: June.

**Q: When's the full commercial product ready?**
A: Assuming pilot approval + Phase 7A/B/C go smooth: Q2 2026 close, Q3 soft launch.

---

#### **Risk & Mitigation**

**Q: What if operators don't feel confident in proofs?**
A: We iterate on Phase 1–6 (simplify, clarify, add transparency). Pilot data guides improvements.

**Q: What if there's a safety issue during pilot?**
A: Immediate pause. All approvals frozen. Engineering investigates. No customer impact (preview-only). Resume after fix validated.

**Q: What if Phase 7A takes longer than expected?**
A: We've built Phase 1–6 to be stable. Can extend pilot while Phase 7A is worked. Pilot doesn't block other work.

**Q: What if customers don't like the proof system?**
A: Phase 1–6 is operator-facing, not customer-facing. Operator sees proofs; customer sees polished PDF only. Customer feedback comes after Phase 7 launch.

---

#### **Future Roadmap**

**Q: Will Button 2 integrate with Button 3 (results matching)?**
A: Yes, in Phase 7D. Export events flow to Button 3 for accuracy validation and learning.

**Q: Can operators customize PDF formats?**
A: By design, no. Consistency is critical for compliance and quality. Custom templates deferred to Phase 8+.

**Q: Will there be mobile/tablet support?**
A: Phase 1–6 is web-based. Mobile support deferred to Phase 8.

**Q: Can we batch-approve multiple reports?**
A: No. Each report requires individual operator approval (by design—safety first).
