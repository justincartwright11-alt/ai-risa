## 3-Button Workflow
1. Build Fight Queue
- Intake and parse matchup rows.
- Operator validates and saves selected fights.

2. Generate Premium PDF Reports
- Operator selects saved fights and exports PDFs.
- Export returns file proof and completeness diagnostics.

3. Compare Results and Improve Accuracy
- Operator reviews result candidates.
- Apply is approval-gated and returns mutation + reason + rollback proof.
